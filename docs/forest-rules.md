# 翠绿小树林生成规则

实现：`demo/forest.js`
预览：`demo/forest.html`

---

## 0. 从参考图到像素规则

参考图是一片阔叶树林，可提取的视觉特征是：

| 参考图特征 | 转译到等距像素 |
|------------|----------------|
| 树冠圆润、成片、互相重叠 | 每棵树由几十个球体堆成扁球状树冠；树间距小于树冠直径，让林冠连成一片 |
| 翠绿色、上亮下暗 | 5 档绿色色阶，按球体高度（tilt）和随机值分配 |
| 树干细、颜色深、有分叉 | 2～3 段胶囊，半径从 0.17 收到 0.05 |
| 草地、树根处有暗部 | 程序化草地 + 每棵树的投影阴影与接触阴影 |
| 前大后小的纵深 | 按 `y` 计算 `depth`，前排树的尺寸略大 |
| 树冠边缘有小的团块凸起 | 表层小球半径随机、位置向水平方向拉伸 10% |

像素风不追求照片级细节，目标是**保留构图和色彩关系**，用球体堆叠代替叶片。

---

## 1. 生成流程

```
1. 地面     椭圆岛 + 草地噪声 + 泥土边缘 + 向下挤出的土层
2. 布点     椭圆区域内拒绝采样，保证最小间距
3. 单树     树干分叉 + 内层大球 + 表层小球
4. 着色     5 档绿色，按 tilt 与随机值取色
5. 阴影     树冠投影（strength 1）+ 树根接触影（strength 2）
6. 草叶     1～3px 的草簇，只落在地面像素上
```

所有步骤只在 `bake` 时执行一次，结果是静态的 `bakedPix` / `bakedZ`。

## 2. 布点规则

```js
const a = rnd(n, 1) * 6.283;          // 角度均匀
const r = Math.sqrt(rnd(n, 2)) * .86; // 半径开方，保证圆内均匀
const x = Math.cos(a) * RX * r;
const y = Math.sin(a) * RY * r;
```

约束：

| 规则 | 值 | 原因 |
|------|-----|------|
| 有效区域 | `islandE(x, y) ≤ 0.84` | 留出岛边缘的草地 |
| 最小间距 | `1.15` 世界单位 | 小于树冠直径，让树冠重叠 |
| 拒绝采样上限 | `count × 140` | 防止参数过大时死循环 |
| 纵深 | `depth = (y + RY) / (2RY)` | `y` 越大越靠前 |
| 尺寸 | `size = (0.86 + depth × 0.3) × (0.9 + rand × 0.28)` | 前排略大，制造层次 |

> 树冠直径约 `2 × 1.5 = 3` 世界单位，最小间距 `1.15`，所以相邻树的树冠必然重叠——这是"成片"的关键。

## 3. 单树规则

### 3.1 尺寸

| 量 | 公式 | 典型值 |
|----|------|--------|
| 树高 `h` | `(2.2 + rand × 0.9) × size` | 2.2–3.1 |
| 树冠半径 `crown` | `(1.3 + rand × 0.45) × size × crownScale` | 1.3–1.75 |
| 树冠中心高度 `cz` | `h × 0.78` | — |
| 树冠垂直压缩 | `0.52` | 扁球，不是正球 |

### 3.2 树干

```js
// 主干
capsule([x, y, 0], [x + leanX, y + leanY, h * .55], .17 * size, .10 * size, bark);
// 主分叉
capsule([bx, by, h * .55], [bx + leanX * .9, by + leanY * .9, h * .80], .09 * size, .05 * size, bark);
// 侧分叉
capsule([bx, by, h * .55], [bx - .3 * size, by + .18 * size, h * .74], .06 * size, .04 * size, bark);
```

- 树干颜色 `[78, 62, 52]`，深棕偏灰
- `leanX / leanY` 在 ±0.175 内随机，让树干不完全垂直
- 分叉从 `h × 0.55` 开始，被树冠遮住大半，只露出下段

### 3.3 双层树冠

**内层：8 个大球**，先把树冠填成连续体块。

```js
d = cbrt(rand) * crown * .55;
radius = crown * (0.50 + rand * 0.18);   // 大球
color = palette[1];                       // 偏暗
z = cz - crown * .12 + (rand - .5) * crown * .3;
```

**表层：26–64 个小球**，做轮廓、亮部和叶簇。

```js
n = clamp(round(26 * crown²), 26, 64);
d = cbrt(rand) * crown;
x/y 方向 × 1.1;                           // 横向拉伸，树冠更宽
z = cz + tilt * d * .52;                  // 垂直压缩
radius = (0.30 + rand * 0.20) * size;
```

为什么分两层：

- 只用小球 → 球与球之间有空隙，树冠像"葡萄串"
- 只用大球 → 表面太平，没有叶簇
- 大球填充 + 小球做表面 → 连续体块 + 颗粒细节

## 4. 着色规则

### 4.1 5 档绿色

| 索引 | 翠绿 `fresh` | 用途 |
|------|--------------|------|
| 0 | `[40, 88, 48]` | 树冠底部、背光 |
| 1 | `[60, 112, 54]` | 内层大球、暗部 |
| 2 | `[86, 138, 62]` | 中间调 |
| 3 | `[116, 162, 74]` | 受光面 |
| 4 | `[148, 186, 90]` | 顶部高光 |

`rampOf()` 会在每档内部再生成 5 级明暗（暗部偏紫、亮部偏暖黄），所以实际颜色比表里更丰富。

### 4.2 取色公式

```js
tone = 0.08 + rand * 0.40 + (tilt * 0.5 + 0.5) * 0.48;
idx  = clamp(floor(tone * 4.999), 0, 4);
```

- `tilt = -1`（球在树冠底部）→ 偏暗
- `tilt = +1`（球在树冠顶部）→ 偏亮
- 随机项保证同一高度也有深浅变化，避免机械渐变

### 4.3 三套调色板

| 名称 | 感觉 |
|------|------|
| `fresh` | 翠绿，参考图主色 |
| `deep` | 深绿，阴天/密林 |
| `autumn` | 秋黄，验证规则的可配置性 |

## 5. 阴影规则

```js
// 树冠投影：大而淡
castShadow(x + leanX * .5, y + leanY * .5, h * .5, crown * 1.15, 1, .55);
// 树根接触影：小而深
castShadow(x, y, 0, size * .2, 2, 0);
```

- `z` 参数决定投影偏移：`x + 1.3z, y - 0.12z`
- `strength 2` 的接触影让树根"踩"在地面上
- `applyShadows()` 只染地面像素，树冠和树干不会被阴影糊住

## 6. 可复现性

所有随机都来自：

```js
const rnd = (a, b) => hash(a * .731 + params.seed * 1.37, b * 1.913);
```

`hash()` 是确定性的 `sin` 哈希。因此：

- 同一组 `(seed, count, crown, palette)` → **完全相同的树林**
- 换 `seed` → 重新布点、重新长树
- UI 的"换一片"按钮就是换 `seed`

## 7. 参数表

| 参数 | 默认 | 范围 | 作用 |
|------|------|------|------|
| `count` | 76 | 20–90 | 目标树数量（放不下时会少一些） |
| `crown` | 1.0 | 0.7–1.4 | 树冠整体缩放 |
| `seed` | 7 | 任意整数 | 随机种子 |
| `palette` | `fresh` | `fresh` / `deep` / `autumn` | 配色 |

内部常量（`forest.js` 顶部）：

| 常量 | 值 | 作用 |
|------|-----|------|
| `RX`, `RY` | 18, 15 | 岛屿椭圆半径 |
| `SOIL_H` | 1.2 | 土层厚度 |
| `minD` | 1.15 | 树的最小间距 |
| `PP_SCALE` | 9 | 每世界单位的像素数 |

## 8. 调参对照

| 想要 | 改 |
|------|-----|
| 更密 | 提高 `count`，降低 `minD` |
| 树冠更大 | 提高 `crown`，或 `(1.3 + rand * .45)` |
| 树林更满 | 提高布点区域 `islandE ≤ 0.84` 到 0.9 |
| 更翠绿/更黄 | 调 `PALETTES.fresh` |
| 更暗的树荫 | 提高树冠阴影的 `strength` 或增大 `crown * 1.15` |
| 树干更明显 | 抬高 `cz`（树冠中心），或加粗树干 |
| 前排更大 | 提高 `depth * 0.3` 的系数 |
| 更自然的轮廓 | 增加表层小球数量、扩大半径随机范围 |

## 9. 已知取舍

- **静态**：没有风摆。加风需要把每个树冠球缓存成 sprite 再逐帧偏移，成本会明显上升。
- **颗粒感**：近看能看出球体堆叠，这是像素风的取舍；远看是连续的树冠。
- **遮挡**：树很密时，后排树干会被完全挡住，只剩林冠——这与真实树林一致。
- **相机固定**：不支持旋转视角，所有深度和阴影计算都依赖固定 30° 正交投影。
- **单次烘焙**：参数变化会整片重绘，拖动滑块时约有几十毫秒的重建成本。
