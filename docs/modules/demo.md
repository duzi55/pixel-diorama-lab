# demo.js — 最小场景与交互

路径：`demo/demo.js`（约 230 行）

## 职责

用 `engine.js` 拼出一个可交互的最小场景：

- 一块椭圆形草地小岛，边缘是泥土，土层向下挤出
- 一栋小木屋（墙、屋顶、烟囱、门、窗）
- 一棵程序化树（胶囊树干 + 球体树冠）
- 三颗球：红球静止、蓝球可拖动、黄球自动绕圈
- 鼠标/触摸拖动蓝球，实时观察阴影、遮挡和深度

## 场景坐标

| 元素 | 世界坐标 | 说明 |
|------|----------|------|
| 岛 | 椭圆 `RX = 12`, `RY = 10` | 超椭圆指数 4，边缘更方 |
| 木屋 | `x ∈ [-6.6, -3.6]`, `y ∈ [-2.6, 0.4]` | `z` 到 1.5，屋顶到 1.85 |
| 树 | `(5, -3.8)` | 树干高 2.35，树冠半径约 1.6 |
| 石头 | `(-1.8, -5.2)` | 两个 rough 球 |
| 红球 | `(3.4, 2.4)` | 半径 0.6 |
| 蓝球 | `(0.6, 3.2)` | 半径 0.6，可拖动 |
| 黄球 | 绕 `(4, -1.5)` 椭圆运动 | 半径 0.42，悬浮 |

## 关键函数

| 函数 | 作用 |
|------|------|
| `islandE(x, y)` | 超椭圆归一化距离，`> 1` 表示岛外 |
| `groundColor(x, y, ix, iy)` | 逐像素决定草/泥土/透明 |
| `bakeSoil()` | 把岛向下挤出 `SOIL_H`，画侧壁 |
| `scatterGrass()` | 在地面撒 1–3px 的草叶 |
| `tree(x, y)` | 树干 + 110 个球体树冠 |
| `bake()` | 画土层、地面、木屋、树、石头、静态阴影，存底图 |
| `update(dt)` | 黄球绕圈、蓝球拖动时抬高 |
| `draw()` | 恢复底图 → 画球 → 阴影 → 描边 → 提交 |

## 渲染顺序（`bake()`）

```
bakeSoil()          土层侧壁（先画，后面会被顶面覆盖）
地面逐像素          草 / 泥土 / 白色背景
scatterGrass()      草叶
box() × 3           墙、屋顶、烟囱
plot()              门、窗
tree()              树干、树冠
sphere()            石头
castShadow()        房子和树的静态阴影
applyShadows()      只染地面
bakedPix.set(pix)   存底图
```

## 交互

| 事件 | 行为 |
|------|------|
| `pointerdown` | 找 16px 内最近的球，设为 `held` |
| `pointermove` | 把指针反投影到地面，限制在岛内 `e ≤ 0.82` |
| `pointerup` / `pointercancel` | 释放 |
| 重置按钮 | 三颗球回到 `home` 坐标 |

拖动时球的 `z` 从 `r` 平滑抬到 `0.95`，松手落回；阴影随高度偏移，是观察投影关系最直观的部分。

## 参数调整

| 想要 | 改 |
|------|-----|
| 岛更大/更小 | `RX` / `RY` |
| 土层更厚 | `SOIL_H` |
| 草更密 | `scatterGrass()` 的循环次数与 `islandE` 阈值 |
| 树更茂盛 | `tree()` 的球数、`d` 半径、球体半径 |
| 球更大 | `balls` 里的 `r` |
| 阴影更柔 | `castShadow()` 的 `dither`（当前动态阴影传 0） |
| 黄球速度 | `update()` 里的 `T * .7` |
