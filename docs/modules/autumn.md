# autumn.js — 秋日野餐

路径：`demo/autumn.js`（约 375 行）
页面：`demo/autumn.html`

## 职责

在 `engine.js` 之上生成一个秋天的等距像素场景：

- 菱形地台（不是椭圆岛），铺满金黄落叶，下边缘挤出土层
- 三棵法国梧桐：笔直的灰白树干、细密分枝、**树上没有叶子**
- 红白格子野餐布，布上有食物和篮子
- 两个人物：一个仰坐撑手，一个双手枕头躺着
- 树随风轻摆，偶发阵风，零星落叶飘下

## 关键设计

### 菱形地台

不在世界空间用曼哈顿距离（那会投影成屏幕上的正方形），而是在 **uv 空间**：

```js
const ru = (x - y) / R2, rv = (x + y) / R2;
const d = Math.abs(ru) / RU + Math.abs(rv) / RV;
```

投影后就是屏幕上的扁菱形（宽高比 2:1）。顶面和侧壁共用同一个判定函数，边界严格对齐。

### 梧桐

整棵树只有 `capsule`，没有 `sphere` 叶簇。分叉是**分层**的，不是从一点井喷：

| 部位 | 做法 |
|------|------|
| 主干 | 从地面到 `0.52h`，半径 `0.25 → 0.16`，笔直 |
| 主枝 | 3 根，从主干顶端分出，半径 `0.11 → 0.065` |
| 细枝 | 每根主枝再分 3 根，半径 `0.048 → 0.010` |
| 树皮 | 上段 `BARK_HI` 灰白，下段 `BARK_LO` 偏冷灰 |

半径比例参考原始项目的 `growTree()`（那边主干 0.36 起、树高 4.9），按本场景的 3.7 左右缩放。梧桐的美在枝干骨架，落叶后就是这个轮廓，不需要任何叶子。

### 人物

比例和骨骼照搬原始项目 `engine.js` 的 `figure()`，按 0.8 缩放：

| 部位 | 半径 | 说明 |
|------|------|------|
| 躯干 | `0.24 → 0.21` | 臀部到肩 |
| 头 | `0.19` | 肩上方约 `0.3` |
| 腿 | `0.14 → 0.11 → 0.09` | 臀 → 膝 → 脚 |
| 手臂 | `0.096 → 0.08 → 0.065` | 肩 → 肘 → 手 |
| 鞋 | `0.09` | 脚端一个小球 |

两个人物都用 `'solid'` 模式（不加抖动），边缘干净，能在地面的噪点里读出形状。

躯干比例是关键：早期版本用 `0.30` 半径配 `0.6` 长度，投影出来像一条毛毛虫。按原项目 `figure()` 的“半径 ≈ 长度 × 0.6”重新收细，人才站得住。

条纹取色分两种：

| 姿态 | 条纹方式 |
|------|----------|
| 仰坐（竖直躯干） | `Math.floor(z * 8) % 2`，z 方向切约 3px 一道 |
| 躺（水平躯干） | 沿身体轴切 3 段，每段约 6px；z 几乎不变，按 z 取色会退化成纯色 |

姿态是原项目没有的，按同样的骨骼重新摆：

- **仰坐**：臀 `z=0.24`，肩后移 `0.32`、抬高到 `1.00`，头在肩上方 `0.28`；远侧腿伸直，近侧腿屈膝抬到 `z=0.58`；双臂肘部外张、前臂垂直撑地
- **躺**：头 `z=0.26`，肩 `+0.40`，臀 `+1.22`；一条腿平伸到 `+2.18`，一条腿屈膝抬到 `z=0.66`；双手枕在脑后
- 躺姿的肩要贴着头，否则细脖子会从头发下面露出来，看着像头掉在旁边
- 躺姿的头发压在头下方（后脑勺贴枕），不是站姿那样浮在头顶

### 静态烘焙 + 每帧重绘人物与树

| 部分 | 时机 |
|------|------|
| 土层、地面、落叶、布、食物、树影 | `bake()` 一次 |
| 人物、树干、枝条、飘叶 | 每帧重绘 |

`draw()` 每帧从 `bakedPix` / `bakedZ` 恢复，再画人和树。人每帧重绘是为了呼吸：

```js
const brA = Math.sin(t * 1.7) * .5 + Math.sin(t * 2.9 + .8) * .5;
const brB = Math.sin(t * 1.4 + 1.2);
```

两个频率不同，避免看出同步的机械感。`br` 只作用在肩、颈、头的 z 上（±0.02~0.03 世界单位，约 0.5px），幅度再大就会闪。人物同时每帧 `castShadow` 出接触影，再 `applyWarmShadows(groundZ)` 只染地面，人不会悬在布上。

### 风

两层叠加：

```js
// 阵风包络：三个低频正弦叠加，阈值化，长时间平静、偶尔起风
gustAt(t) = max(0, sin(...)*.5 + sin(...)*.3 + sin(...)*.2 - .28) / .72

// 单树摆动：两个高频正弦，幅度受阵风放大
swayAt(t, phase, gust) = (sin(t*2.9 + phase)*.6 + sin(t*5.1 + phase*2.1)*.4) * (.09 + gust*.38)
```

`sway` 同时驱动树干顶端的弯曲量（`sway * .18`）和每根枝条末端的偏移（`sway * rise`），所以整棵树是"从根到梢"的摆动，不是整体平移。

## 关键函数

| 函数 | 作用 |
|------|------|
| `islandE(x, y)` | uv 空间的曼哈顿距离 + 噪声扰动 |
| `clothAt(x, y)` | 野餐布的格子、包边、布料噪声 |
| `groundColor()` | 逐像素决定落叶地 / 野餐布 / 透明 |
| `bakeSoil()` | 地台向下挤出 `SOIL_H`，只画屏幕下半部分的两条可见侧壁 |
| `scatterLeaves()` | 撒 2200 片 1–2px 的落叶 |
| `basket()` / `food()` | 藤篮、法棍、水果、奶酪、派、杯子 |
| `sitPerson()` | 仰坐：腿前伸、躯干后仰、双手撑地、呼吸 |
| `liePerson()` | 躺：头枕双手、一条腿屈膝、呼吸 |
| `drawTree()` | 主干 + 5 根主枝 + 15 根细枝 |
| `gustAt()` / `swayAt()` | 阵风包络与单树摆动 |
| `applyWarmShadows()` | 暖色阴影，避免把金色地面染成泥坑 |

## 渲染顺序

```
bakeSoil()         地台侧壁
地面逐像素          落叶 / 野餐布 / 透明
scatterLeaves()    1~2px 落叶
basket() / food()  布上的东西
castShadow() × N   枝影
applyWarmShadows() 只染地面
bakedPix.set()     存底图

每帧：
pix.set(bakedPix); zb.set(bakedZ);
sitPerson()        仰坐的人（带呼吸）
liePerson()        躺着的人（带呼吸）
applyWarmShadows() 人物接触影，只染地面
drawTree() × 3     主干 + 枝条（带 sway）
shadeEdges()       深度描边
drawMotes()        飘叶（最后画，避免被描边压暗）
putImageData()
```

## 与 forest.js 的差异

| 项 | forest.js | autumn.js |
|----|-----------|-----------|
| 地面 | 超椭圆岛 | uv 空间菱形 |
| 树 | 阔叶，球体树冠 | 梧桐，无叶，只有枝干 |
| 树的数量 | 20–90，参数化 | 固定 3 棵 |
| 动画 | 静态 | 12fps，风动 + 飘叶 |
| 人物 | 无 | 两个 |
| 阴影 | `applyShadows()` | `applyWarmShadows()` 暖色 |

## 修改指南

| 想改什么 | 改哪里 |
|----------|--------|
| 地台大小 | `RU` / `RV` |
| 地台厚度 | `SOIL_H` |
| 树的棵数/位置/高度 | `TREES` 数组 |
| 树的形态 | `drawTree()` 里的主枝数、`reach`、`rise` |
| 风速/摆动幅度 | `gustAt()` 的阈值、`swayAt()` 的 `.09 + gust*.38` |
| 飘叶数量 | `motes` 初始化循环 |
| 人物姿态 | `sitPerson()` / `liePerson()` 的坐标 |
| 布的格子大小 | `CLOTH.cell` |
| 地面色调 | `FLOOR` |
| 阴影浓度 | `applyWarmShadows()` 的 `tint` 系数 |

## 已知取舍

- **人物小**：等距场景里人只有 20 多像素高，姿态靠色块和轮廓辨认；要更清楚只能放大人物，会破坏与树的真实比例。
- **树是枯的**：梧桐秋天落叶后本来就没有叶子，这不是没画完。
- **侧壁只在屏幕下半部分**：等距挤出体朝上的两条边被顶面挡住，只有下边缘可见。
- **阴影偏淡**：暖色阴影保留了地面的金色，代价是浓度低于冷色阴影。
- **12fps 步进**：像素风动画故意降帧，既省性能又有顿挫感。
- **人物只有呼吸**：点头、眨眼这类动作在 20 多像素高的人身上读不出来，反而会闪；所以只保留肩颈的轻微起伏。
