## 1. `ball` 球

- **来源**：`balote:412-416`（滚球/jack）· `tie-break:534-539`（网球）· props.md §1
- **实现**：`demo/kit/ref-props.js:82`
- **形态**：贴地的小球，`gloss` 球面光照 + 一圈网球缝线 + 双层影。

### 参数

| 参数 | 默认 | 区间 | 含义 |
|------|------|------|------|
| `r` | .45 | .15-1.2 | 球半径 |
| `color` | 0 | 0-5 | 配色索引：网球黄绿 / 红 / 蓝 / 芥末黄 / 白 / 橙 |
| `seam` | 1 | 0-1 | 是否画网球缝线 |

### 关键算法

```js
ctx.sphere(X, Y, Z + R, R, rpPick(RP_BALL_COLORS, P.color), 'gloss');
// 缝线 = 球面大圆，半径放大 1.5%，否则被球体自身深度挡掉
for (let a = 0; a < 6.2832; a += .09)
  ctx.plot(X + cos(a)*rr*.85, Y + sin(a)*rr, Z + R + cos(a)*rr*.53, ink);
ctx.shadowAt(X, Y, Z, R * 1.15, 1, .5);
if (Z < .1) ctx.shadowAt(X, Y, Z, R * .72, 2, 0);
```

- 球心必须在 `Z + R`，不是 `Z`。
- 缝线平面基向量取 `u=(.85,0,.53)`、`v=(0,1,0)`，两者正交。
- 缝线半径 `R*1.015`：只多 0.1px，但能通过深度测试。

### 移植清单

1. `sphere` 用 `'gloss'`（写死高光，球才读得出球）。
2. 投影影 + 贴地接触影两层，半径 `.96` 的感受用 `1.15 / .72` 近似。
3. 缝线是可选项；关掉就是一个纯色球。

### 坑

- 用 `'solid'` 球会糊成一块圆片，**必须 `'gloss'`**。
- `plot` 直接画在球面同深度会被 `p.d <= zb[i]` 拒掉 → 半径放大。
- 默认 `r=.45` 是为了 >60px 的验收阈值；参考项目网球只有 `.22`，按场景需要调小即可。

## 2. `bottle` 瓶

- **来源**：`balote:140-141`（绿色玻璃瓶）· props.md §2
- **实现**：`demo/kit/ref-props.js:117`
- **形态**：细颈瓶：瓶身 → 瓶肩 → 瓶颈 → 瓶口，四段竖直胶囊接成。

### 参数

| 参数 | 默认 | 区间 | 含义 |
|------|------|------|------|
| `r0` | .3 | .08-.5 | 瓶身半径（下粗） |
| `r1` | .1 | .03-.3 | 瓶颈半径（上细） |
| `height` | 1.35 | .3-2 | 瓶高 |
| `color` | 0 | 0-3 | 墨绿 / 琥珀 / 蓝 / 乳白 |
| `cork` | 1 | 0-1 | 是否带软木塞 |

### 关键算法

```js
bodyTop = Z + H*.62; shoulderTop = Z + H*.76; neckTop = Z + H*.93;
capsule([X,Y,Z+R0], [X,Y,bodyTop], R0, R0, glass, 'gloss');      // 瓶身
capsule([X,Y,bodyTop-.02], [X,Y,shoulderTop], R0, R1, glass, 'gloss'); // 肩
capsule([X,Y,shoulderTop], [X,Y,neckTop], R1, R1, glass, 'gloss');     // 颈
capsule([X,Y,neckTop], [X,Y,Z+H], R1*1.3, R1*1.1, glass, 'gloss');     // 口
```

- 四段胶囊用**同一个玻璃色**，重叠处不会出现接缝。
- 瓶口 `R1*1.3` 那一圈是"瓶"读得出来的关键。
- 软木塞用 `'rough'`，和玻璃的 `'gloss'` 拉开材质差。

### 移植清单

1. `capsule` 的颜色回调返回基色数组（不是打包值）。
2. 底端中心抬到 `Z+R0`，胶囊底球才正好落在地面。
3. 阴影两层：瓶身大影 + 瓶底接触影。

### 坑

- `r1 > r0` 不会崩，但会读成"罐"或蘑菇；需要瓶形时保持 `r1 < r0`。
- `height` 很小时 `bodyTop < Z+R0`，胶囊方向反转 —— 不崩，但形状会压扁。
- 默认尺寸同样为了验收像素数放大；真实比例的瓶子只有 ~10px 高。

## 3. `wicker-basket` 藤篮

- **来源**：`laundry:169-175`（屋顶洗衣的藤篮）· props.md §4
- **实现**：`demo/kit/ref-props.js:154`
- **形态**：圆周扫掠的编织圆篮，横竖两组条纹交错，篮口有深色包边。

### 参数

| 参数 | 默认 | 区间 | 含义 |
|------|------|------|------|
| `r` | .6 | .2-1.4 | 篮口半径 |
| `h` | .75 | .25-1.6 | 篮深 |
| `color` | 0 | 0-2 | 藤黄 / 深棕 / 灰柳 |
| `handle` | 0 | 0-1 | 是否加跨篮提手 |

### 关键算法

```js
const weave = (Math.floor(z / H * 6) + Math.floor(t * 7)) % 2;
let lv = Math.round(2.6 - .5*nx + .85*ny) + weave - 1;
if (z > H - .08) lv += 1;                     // 篮口提亮
ctx.plot(X + nx*R, Y + ny*R, Z + z, ramp[clamp(lv,0,4)]);
```

- `z/H*6 × t*7` 两组条纹交错 → 藤编网格；系数不要写成固定 `z*8`，否则换 `h` 后纹路密度会变。
- 柱面亮度公式 `2.6 - .5*nx + .85*ny` 与 `roundTower` 同源（stari-most:162）。
- 篮口再补外圈 + 内圈两道 → 厚度。
- 提手用 10 段直线胶囊拼半圆弧（`capsule` 只能画直线）。

### 移植清单

1. 先铺暗色篮底（`z=.015` 圆盘），再扫掠篮壁。
2. 只用 `plot`，颜色全部走 `rampOf`。
3. 篮口环最后画，盖住壁顶的锯齿。

### 坑

- 底部圆盘别用 `sphere` 压扁（没有扁球原语），用逐点圆盘。
- `t` 步长 `.02`、`z` 步长 `.045`：再细会重复写同一像素，白费 CPU。
- 提手默认关：独立摆件不一定要提手，开起来在场景里更像"篮子"。

## 4. `cloth` 织物

- **来源**：`laundry:226-281`（`inside()` 轮廓裁剪 + `drawCloth()` 波浪）· props.md §5
- **实现**：`demo/kit/ref-props.js:217`
- **形态**：挂在绳上的布。5 种轮廓、波浪下摆、可整片斜挂、可加条纹。

### 参数

| 参数 | 默认 | 区间 | 含义 |
|------|------|------|------|
| `w` | 1.6 | .4-3 | 布宽 |
| `h` | 1.6 | .3-3 | 垂下长度 |
| `kind` | 0 | 0-4 | 床单 / 毛巾 / 衬衫 / 裤子 / 袜子 |
| `color` | 1 | 0-6 | 7 色布 |
| `stripe` | 0 | 0-1 | 是否加条纹 |
| `tilt` | 12 | 0-80 | 斜挂角度（度，下摆向 +x 偏） |
| `top` | 1.75 | .3-3 | 挂绳离地高度 |

### 关键算法

轮廓裁剪照抄 `laundry:226-232`：

```js
if (k === 2) return a < w*.32 || v < h*.34 + (a - w*.32)*-.3; // 衬衫
if (k === 3) return v < h*.34 || a > .06;                     // 裤子
if (k === 4) return v < h*.62 ? a < w*.3 : u > -w*.3;         // 袜子
```

绘制（参照 `drawCloth`）：

```js
const wave = u*3.2 + v*1.2 + phase;
const reach = v / H + .12;              // 顶端固定，下摆摆幅大
px = X + u + v*sinT;                    // tilt 剪切：整片布斜挂
py = Y + sin(wave)*.08*reach;
pz = max(Z+.03, topZ - v*cosT);
lv = clamp(3 + round(cos(wave)*1.1), 0, 4);
```

- 波浪频率 `u*3.2`（横向几个波）与 `v*1.2`（纵向相位差）都来自参考实现。
- 条纹：床单沿 `u` 分条，其余沿 `v` 分条（`laundry:258` 同款）。
- 挂绳用抛物线垂弧 `sag = .035*(1-(u/uMax)²)`（props.md §5.5）。
- 两只衣夹落在绳上，给"挂着"一个视觉落点。

### 移植清单

1. 轮廓函数独立成 `rpClothInside()`，参数化 `kind`。
2. `tilt` 是 x-z 平面的**剪切**，不是绕 y 轴旋转（旋转会让顶边倾斜）。
3. `pz` 夹到 `Z+.03`：极端参数（`top` 小、`h` 大）时布会"堆"在地面而不是穿下去。
4. 颜色用 `rampOf`，`alt` 取色板里隔 3 位的颜色，条纹不撞色。

### 坑

- `phase` 必须来自 `ctx.hash(1, ctx.seed)`，不能 `Math.random()`。
- `u` 步长 `.055`，再细不会更清楚（投影后不足 1px）。
- `kind` 是数字枚举；想加新轮廓就扩 `rpClothInside()`，不要另建构件 ID。

## 5. `racket` 球拍

- **来源**：`tie-break:492-504`（人物手上的拍）· props.md §6
- **实现**：`demo/kit/ref-props.js:280`
- **形态**：**平放**的球拍：椭圆拍面 + 拍线网 + 拍喉 + 拍柄 + 握把。
  参考项目里球拍是挂在人物手上的，这里改成可独立摆放的地面道具。

### 参数

| 参数 | 默认 | 区间 | 含义 |
|------|------|------|------|
| `len` | 1.25 | .5-2.2 | 拍柄长度 |
| `faceR` | .55 | .18-.95 | 拍面半径 |
| `strings` | 1 | 0-1 | 是否画拍线网 |
| `color` | 0 | 0-3 | 红框 / 蓝框 / 黑框 / 木框 |

### 关键算法

```js
// 拍面：水平椭圆逐点填充，外圈 R*.09 是拍框
if (u*u + v*v > R*R) continue;
if (edge < rimW) frame[...] else face[...];
// 拍线：显式画线，抬 z .002 避免与拍面同深度被拒
for (let u = -R+gap*.5; u < R; u += gap)
  for (let v = -half+.02; v <= half-.02; v += .035)
    ctx.plot(cxF+u, Y+v, zf+.002, stringInk);
```

- 拍面在 **x-y 平面**（贴地），所以屏幕上看到的是压扁的椭圆，面积只有圆的一半。
- 拍线不靠网格采样"碰运气"，而是按固定 `gap` 逐条画线，保证连续。
- 拍喉两根斜胶囊 + 拍柄一根直胶囊 + 握把（半径 ×1.12）接在拍面 +x 侧。

### 移植清单

1. 拍面填充与拍线分两遍；先填后线。
2. 拍线抬高 `.002` 是为了过深度测试（`p.d <= zb` 会拒同深度）。
3. 阴影一根长椭圆即可，不必给柄单独投影。

### 坑

- 拍面半径按真实比例只有 `.16` 左右，屏幕上不到 10px；默认 `.55` 是为了可读性放大。
- `faceR` 很小时 `step = max(.03, R/14)` 兜底，避免循环次数爆炸。
- 拍线与拍框不要用同一颜色，否则整片糊成一块。

## 6. `cone` 交通锥

- **来源**：`mini-ramp:201-203`（锥 + 白色反光带）· props.md §2.1
- **实现**：`demo/kit/ref-props-small.js:49`
- **形态**：橙红锥体 + 白色反光带 + 方形配重座。

### 参数

| 参数 | 默认 | 区间 | 含义 |
|------|------|------|------|
| `r0` | .42 | .15-1 | 锥底半径 |
| `r1` | .05 | .02-.2 | 锥尖半径 |
| `h` | 1 | .3-2 | 锥高（含底座） |
| `band` | 1 | 0-1 | 是否画白色反光带 |

### 关键算法

```js
for (let z = .05; z <= H; z += .035) {
  const rz = lerp(R0, R1, z / H);
  const band = P.band && z > H*.42 && z < H*.64;
  const rmp = band ? white : orange;
  for (let t = 0; t < 6.2832; t += .02)
    ctx.plot(X + cos(t)*rz, Y + sin(t)*rz, Z + z, rmp[clamp(2.8 - .5*nx + .85*ny + band, 1, 4)]);
}
```

- **一叠同轴圆环**，半径逐层 `lerp(R0,R1)` → 实心锥面。
- 反光带按高度比例分段（`.42H ~ .64H`），换 `h` 后位置自动跟随。
- 白带整体亮度 +1，避免被橙色的色阶压灰。
- 方形底座用 `box`，比锥底大 8%。

### 移植清单

1. 底座 → 锥体 → 阴影。
2. 不要用单根 `capsule(z=0 → h)`：底球的半球会鼓到地面以下。
3. 亮度公式沿用藤篮/柱面那一套，锥体才有体积。

### 坑

- 圆环采样步长 `.02`，粗了会出现一圈圈条纹（每层环之间露缝）。
- `r1` 不要设 0（参数下限 `.02`），否则尖端会缺像素。
- 白带的范围是**比例**不是绝对高度，短锥和长锥都好看。

## 7. `bench` 长椅

- **来源**：`balote:134-137` · `tie-break:160-165` · props.md §7
- **实现**：`demo/kit/ref-props-small.js:91`
- **形态**：几条交替木色的座板 + 靠背 + 两条铁脚。

### 参数

| 参数 | 默认 | 区间 | 含义 |
|------|------|------|------|
| `len` | 2.6 | 1-6 | 椅子长度 |
| `h` | .85 | .35-1.4 | 座面高度 |
| `slats` | 3 | 1-7 | 座板条数 |
| `back` | 1 | 0-1 | 是否带靠背 |
| `color` | 0 | 0-2 | 暖木 / 深胡桃 / 灰木 |

### 关键算法

```js
const D = clamp(LEN * .22, .45, .85);   // 座深随长度走
// 座板：沿长度通铺，板间 .022 缝，奇偶交替色
for (let i = 0; i < n; i++) {
  const sy0 = y0 + D*i/n, sy1 = y0 + D*(i+1)/n - gap;
  box(x0, sy0, seatTop-seatT, x1, sy1, seatTop, i % 2 ? set[1] : set[0], seed+i);
}
```

- 靠背放在 **-y（远侧）**：`box(..., y0-.1, seatTop+.02, ..., y0+.01, seatTop+.56, ...)`。
- 两条铁脚 + 两根靠背立柱，都用同一个深铁色。
- 落地影沿 x 每 `.65` 投一颗，连成一条"椅子影"。

### 移植清单

1. 木色成对给（`set[0]` / `set[1]`），交替色才读得出板条。
2. 每块板给不同 `seed`，否则木纹完全重复。
3. `slats` 用 `Math.round` 转整数；`n=1` 时就是一条整板。

### 坑

- 靠背放错到 +y（近侧）会挡住座面，看起来像一张桌子。
- 座深 `D` 必须夹住：`len=6` 时若按 `.22` 会是 1.32，椅子太笨。
- 座板缝 `.022` 别省，否则整排板读成一块厚木头。

## 8. `awning` 遮阳篷

- **来源**：杆件写法参照 `laundry:147-148`（天线/横杆）· 布面扫掠参照 `laundry:233` 的逐点布料
  · 条纹配色参照 `tie-break:160-165` 的板条交替。参考项目**没有现成遮阳篷**，本卡按
  "斜挑条纹布篷"重构，`structures.md §4.5` 里的 `awning` 其实指的是天线（aerial），不要混淆。
- **实现**：`demo/kit/ref-props-small.js:149`
- **形态**：从墙（-y 侧）斜挑出来的条纹布篷，外沿有波浪垂边，可加两根前支柱。

### 参数

| 参数 | 默认 | 区间 | 含义 |
|------|------|------|------|
| `w` | 2.6 | 1-6 | 篷面宽度（x） |
| `d` | 1.5 | .5-3 | 伸出深度（y） |
| `height` | 2.2 | .8-3.5 | 靠墙端离地高度 |
| `stripe` | .3 | .1-.8 | 条纹宽度 |
| `slope` | .45 | .05-1.2 | 前后高差 |
| `color` | 0 | 0-3 | 红白 / 蓝白 / 绿米 / 橙米 |
| `posts` | 1 | 0-1 | 是否加前支柱 |

### 关键算法

```js
// 篷面：u 宽度 × v 伸出；v 越大 z 越低，中间再加一点布的自重下垂
const lv = clamp(3 + round(cos(u*2.1)*.35 - t*.9), 1, 4);
ctx.plot(X + u, yWall + v, zh - t*slope - sin(t*PI)*.05, rmp[lv]);
```

- 条纹判定：`floor((u + w/2) / stripe) % 2` → 条纹沿 y 方向通铺，宽度可调。
- 外沿垂边：`hem = .12 + .06*(.5+.5*sin(u*5.5))` → 波浪下缘。
- 垂边整体往 **+y 推 .02**，否则和篷面最后一排同深度被拒。
- `slope` 渲染时夹到 `H*.8`，防止极端参数把外沿压进地下。
- 前支柱用细方铁杆；墙侧一条挂杆。

### 移植清单

1. 篷面是 (x,y) 平面上的曲面，不是 x-z 竖直面。
2. 先画篷面，再画垂边、挂杆、支柱，最后铺篷下软影。
3. 阴影分格采样（每 `.55 × .5` 一颗，strength .5），不要一个大圆。

### 坑

- 垂边与篷面同 `y` 会因同深度被拒 → `yFront + .02`。
- `stripe` 太小（<.15）时条纹会碎成噪点；下限 `.1` 已给出，但视觉上 `.25-.4` 最好。
- 没有墙时支柱要开（`posts=1`），否则篷面悬空。

## 9. `ball-basket` 球筐

- **来源**：`tie-break:168-170`（筐 + 9 个散落网球）· 网眼算法来自 `tie-break:108`（wire-fence）
- **实现**：`demo/kit/ref-props-small.js:222`
- **形态**：铁丝网圆筐，暗色筐底，里面堆着网球。

### 参数

| 参数 | 默认 | 区间 | 含义 |
|------|------|------|------|
| `r` | .55 | .2-1.2 | 筐口半径 |
| `h` | .65 | .25-1.4 | 筐高 |
| `balls` | 5 | 0-12 | 筐内球数 |
| `color` | 0 | 0-1 | 全网球黄绿 / 杂色球 |

### 关键算法

```js
// 侧网：菱形网眼 = 两组斜线求交；s 用弧长，网眼在圆周上大小一致
const s = t * R;
const f = (s + z) * mesh, g = (s - z) * mesh;
if (frac(f) > wireW && frac(g) > wireW) continue;
// 球：三个 hash 分别控制角度、半径、高度
const a = hash(k*3+1, seed)*6.2832;
const dist = sqrt(hash(k*3+2, seed)) * R*.55;
const bz = Z + H*.55 + hash(k*3+3, seed)*br*.9;
```

- 用**弧长** `t*R` 而不是角度，筐大筐小的网眼密度一致。
- `wireW=.13`：再大网面会糊成实心桶，再小会稀疏到看不出筐。
- 筐口内外双圈；筐底暗色圆盘给"里面"一个底。
- 球用 `gloss`，位置全来自 `hash`，刷新场景不重排。

### 移植清单

1. 底 → 侧网 → 筐口 → 球 → 阴影。
2. 球在网后画：深度测试会保留靠近相机的网线。
3. 球半径 `clamp(R*.34, .12, .28)`，换筐径时球不会溢出。

### 坑

- 网眼公式里 `s+z` / `s-z` 的两组线必须都判 `frac`，只判一组会变成斜条纹。
- `balls=0` 时筐仍然成立；但默认 5 个球才读得出"球筐"。
- 球心太低会穿出筐底；`bz` 从 `H*.55` 起，配合球半径已足够。
